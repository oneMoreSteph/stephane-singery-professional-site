Rail links are schematic connections between city locations, not a track survey. The Lille–Marseille example and the Swiss/Italian links illustrate coordination, not an assertion about a particular historical train. Paris hubs and delivery rounds illustrate operating roles, not verified historical street addresses. The Tour de France scene is an illustrative crossing, not a specific edition's route.

EU map in "Why Europe": Natural Earth 1:50m Admin 0 Countries, public domain, retrieved 5 November 2026. Built by scripts/build-eu-geography.py. Overseas territories are left out; country boundaries are shown as published by Natural Earth.
